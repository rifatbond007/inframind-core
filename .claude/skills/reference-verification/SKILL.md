# Reference verification (skill entrypoint)

**Canonical procedure:** [`docs/standards/12-paper-writing.md`](../../../docs/standards/12-paper-writing.md) (references section)

Before submission:

1. Load the `reference-verifier` agent (`.claude/agents/writing/reference-verifier.md`).
2. Confirm or fix every entry in `paper/references.bib`; remove unverifiable citations.
3. Log verification status in `docs/PROGRESS.md`.

Do not invent DOIs or venues.
